Docentix es una plataforma multi-institución para gestionar tareas, permisos y
operaciones académicas. Esta documentación explica cómo usar el producto
desde la perspectiva de cada rol: docente, administrador de institución y
operador de plataforma.

## Por dónde empezar

La documentación está organizada por flujos del producto. Cada sección cubre
un área del sistema:

- **Autenticación**: cómo crear tu cuenta, iniciar sesión y recuperar acceso.
- **Onboarding**: primeros pasos al ingresar a una institución.
- **Instituciones**: gestión de la institución, miembros y configuración.
- **Invitaciones**: invitar a docentes y administradores.
- **Tareas**: crear, asignar y dar seguimiento a tareas.
- **Permisos**: cómo funcionan los roles y qué puede hacer cada uno.
- **Plataforma**: documentación específica para operadores de Docentix.

Esta documentación se publica de forma pública y se actualiza en pasos
asistidos. Si encuentras algo desactualizado, abre un issue en el repositorio.
